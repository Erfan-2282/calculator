# Simple Calculator
A simple graphical calculator built with Python and Tkinter.

The calculator has a basic interface with buttons for entering numbers and arithmetic operators. It also handles invalid expressions by displaying an error message.

## Features
* Basic arithmetic operations: addition, subtraction, multiplication, and division
* Decimal numbers
* Error handling for invalid expressions
* Simple dark-themed interface
* Buttons for clearing and editing the current expression

## How to Run
Make sure Python is installed, then run:

```bash
Python calculator.py
```

## Note
This is a small practice project for learning Tkinter and building graphical user interfaces with Python.
